# D1 回测系统

## 完成范围

D1 使用自研回测框架，分成两个稳定接口：

- `BacktestEngine.run(BacktestRequest)`：负责单只股票的撮合、资金持仓、成本、公司行为和绩效；
- `BacktestExperimentRunner.run(...)`：负责固定股票池、C3 信号适配、真实基准和多股票组合汇总。

调用方不需要自己维护现金、持仓、平均成本或权益曲线。所有金额和比例使用 `Decimal`，真实交易始终关闭。

## 无未来数据时间语义

回测区分三个时间：

```text
signal_at：形成判断所对应的已完成 K 线时间
available_at：Agent 真正生成并可使用该信号的时间
execution_at：回测允许成交的下一可交易开盘时间
```

若 Agent 在下一交易日开盘后才生成报告，该日 09:30 不允许成交，信号会继续等待。`C3DecisionSnapshot` 还要求每条证据同时提供：

- `as_of`：事实描述哪个历史时点；
- `available_at`：当时何时真正可以获得；
- `source`：数据来源。

证据晚于信号 K 线，或当时尚未发布，都会在进入回测前被拒绝。C3 报告还会重新经过 `validate_financial_graph_report`，防止最终决策、条件路由和交易安全字段被篡改。

## 撮合、成本和市场约束

- T 日收盘信号最早在下一可交易日 09:30 按开盘价执行；
- 成交量为 0 时视为停牌并继续等待；
- `TradingSessionConstraint` 提供开盘前已知的买卖方向权限，可表达涨停不能买、跌停不能卖或其他交易所限制；
- 信号生成晚于开盘、停牌或方向受限都会留下明确 trace；
- 买卖各计滑点，双边计佣金，卖出计印花税，买入按 100 股整手并检查现金。

回测使用未复权真实成交价，不直接使用可能包含未来调整因子的前复权价格。分红、送股和拆并股通过 `CorporateAction` 在除权除息日显式调整现金、股数和持仓成本；公司行为必须在生效日开盘前已经公告。这相当于在原始价格上还原投资者真实经济权益。

## 指标和边界

单股票和组合层均输出总收益率、最大回撤、年化夏普；单股票还输出已平仓次数、胜率、盈亏比、滑点、佣金、印花税和每日权益曲线。

没有平仓交易时胜率为 `null`，没有亏损交易时盈亏比为 `null`。系统不会把“没有样本”显示为 0% 或无穷大。

## 固定真实数据实验

固定配置位于 `Workflow/examples/d1_backtest_experiment.json`：

- 股票池：`sz000001`、`sh600000`、`sh601398`；
- 时间区间：2025-08-07 至 2026-08-07；
- 每只股票 243 根腾讯真实日线；
- 基准：沪深 300，共 243 根真实指数日线；
- 初始资金：300000 元，三只股票等额分配；
- 佣金 0.03%、最低 5 元、卖出印花税 0.05%、滑点 5 个基点；
- 夏普基线：严格大于 0.5。

行情快照位于 `tests/fixtures/d1_real_market_pool.json`，带有 `source`、`timestamp` 和 `as_of`，测试和演示不依赖网络。需要刷新时才运行 `Scripts/capture_d1_market_pool.py`。

固定实验使用“滚动 Agent 规则生成的 C3 合约格式回放输入”验收接口和时间门禁，明确不冒充过去真实运行过的四 Agent 结论。真正的历史四 Agent 策略评估还需要长期积累带发布时点的行业、估值、资金流和宏观快照；当前实时数据不能倒灌到过去。

## 当前正式结果

```powershell
D:\Anaconda\python.exe Scripts\demo_backtest_experiment.py
```

2026-08-10 固定结果：

- 30 个滚动信号，11 次模拟成交；
- 组合收益率 `-0.5408%`；
- 最大回撤 `0.7754%`；
- 年化夏普 `-0.8463`，没有达到 `> 0.5` 基线；
- 沪深 300 同期收益率 `14.0904%`；
- 相对沪深 300 超额收益 `-14.6312%`；
- 总交易成本 `164.41` 元，其中佣金 `55.00` 元、印花税 `29.10` 元、滑点 `80.31` 元；
- `simulation_only=true`、`order_created=false`、`real_trading_allowed=false`。

没有为了追求 0.5 使用未来数据或反复调参。未达标的直接原因是固定的简单均线趋势 Agent 回放在这组三只银行股上存在滞后，期间整体明显跑输基准；它只能验证回测工程，不能证明完整四 Agent 策略表现。

终端还会运行一组明确标注为合成事件的机制验收，直观看到两次涨跌停方向拦截和一次分红送转处理。这些事件只验证功能，不冒充真实公司行动。
